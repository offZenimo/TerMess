"# TerMess" 
Две консольные программы: сервер и клиент. Несколько клиентов подключаются к серверу по TCP, входят в учётную запись, обмениваются личными сообщениями и получают историю из SQLite. Сервер хранит данные и определяет, кому разрешено их читать.

Близнюк: frontend + testing
Деревяшкин: marketing + backend
Курленя: backend
