# TerMess

TerMess — консольный TCP-мессенджер. В текущей версии можно зайти под уникальным ником и отправлять личные сообщения другим подключённым клиентам. Сервер и клиенты запускаются на одном компьютере и общаются через `127.0.0.1`. Учётные записи и история в SQLite запланированы для следующих этапов.

## Запуск

Нужны Linux или macOS, `make` и компилятор с поддержкой C++17.

```bash
make
./build/termess-server
```

Откройте два других терминала. В первом запустите `./build/termess-client alice`, во втором — `./build/termess-client bob`. В терминале Alice введите `/msg bob Привет!`. У Bob появится `alice: Привет!`, а для ответа можно ввести `/msg alice Привет!`. Для выхода введите `/quit` или нажмите Ctrl+D.

По умолчанию используется порт `5555`. Другой порт можно передать последним аргументом обеим программам, например `./build/termess-server 6000` и `./build/termess-client alice 6000`.
